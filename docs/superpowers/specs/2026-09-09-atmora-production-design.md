# Atmora Production Website Design

## Goal
Build a cinematic marketing experience that explains atmospheric water generation through the physical threshold of condensation and the evidence threshold of verification, while remaining explicit about concept hardware and synthetic data.

## Creative system
**Condensation Observatory.** Macro narrative: atmosphere → condensation → water → evidence → decision. The hero is `WATER IS ALREADY HERE.` The signature interaction is a native-scroll dew-point crossing sequence. Dark cinematic chapters alternate with light scientific/product chapters.

## Product truth
Device and cutaway imagery stays labelled concept/illustrative. Synthetic dashboard and batch material stays labelled synthetic. Raw condensate, treated water, verification and verified-for-intended-use remain distinct. No unsupported yield, SEC, certification, customer, pilot or AI claims are introduced.

## Stack and interaction
React + TypeScript + Vite. Native scroll is the only scroll authority. Motion is CSS/native and restrained. No mandatory WebGL runtime. Reduced motion exposes the full condensation story as static semantic stages.

## Responsive + accessibility
Explicit art direction at 1440, 1280, 1024, 768, 430, 390 and 360. Mobile is recomposed rather than scaled. Target WCAG 2.2 AA: semantic landmarks/headings, keyboard access, visible focus, labelled form controls, 44px controls, text-first evidence states, reduced-motion parity and useful image alt text.
